# Contributing

Thanks for your interest in contributing!

## Ways to contribute

### External contributors

Open a pull request. All pull requests from external contributors are
reviewed by a maintainer before being merged — no PR is merged without
review.

### Maintainers of this repository

If you want to make changes without going through
the standard review flow (e.g. large refactors, frequent small commits,
fast-tracked merges), please open an issue or a discussion first to agree
on this with the other current maintainer(s) before doing so. Unreviewed
direct pushes/merges are not the default workflow for this project.

## Reporting security vulnerabilities

Please do not open a public issue for security vulnerabilities. Use the
repository's **Security** tab (private security advisories), which only
maintainers of this repository have access to.

See `SECURITY.md` (if present in this repository) for the full
vulnerability handling policy.
